# EE: піктограми об’єктів

Піктограми мають прозоре тло, кольоровий силует і світлий контур. Карта, стрічка та картка вибраної сутності використовують спільний вибір за полями `targetType`, `launchType`, `aircraftType`, `model`, `targetModel`, `subtype` (також підтримано snake_case для складених назв).

Окремі силуети: ракета, крилата й балістична ракети, Шахед, Герань, Гербера, реактивний БпЛА, розвідувальний БпЛА, FPV, загальний БпЛА, літак, авіабомба. Зліт і запуск показують об’єкт під кутом із позначенням руху. Без достатніх даних використовується загальна піктограма; текст повідомлення та назви місць не використовуються для вгадування типу.

Власний SVG має пріоритет. В адмінці кнопка «Автоматично за типом об’єкта» очищає перевизначення. Раніше збережені власні піктограми автоматично не замінюються.

Екстрактори розрізняють `geran_drone`, `gerbera_drone`, `shahed_drone`; реактивна Герань зберігає `jet_drone`. Для застосування до нових повідомлень потрібне оновлення збереженого коду екстракторів штатним `entity-extractor/extractors/install.py`. Історичні записи автоматично не перекласифіковуються. Зміни не розгорнуто в живому стеку в межах цієї задачі.

Перевірки: unit-тести вибору силуетів, одночасних типів на карті та звільнення невикористаних зображень; Python-тести екстракторів; браузерні сценарії `PublicEntityIcons.e2e.ts` із двома темами та знімком усіх піктограм. Публічний і адміністративний dev-сервери отримали окремі кеші залежностей після відтвореної помилки 504 Outdated Optimize Dep під час паралельного запуску.
