## План виконання

1. Узгодити оболонку, лічильники, список і стани оновлення з EE.
2. Виправити підтримані фільтри, часові межі й каталог; забезпечити скасування та захист від запізнілих відповідей.
3. Виправити мобільне компонування, клавіатуру й відтворення історії.
4. Додати регресійні unit та Playwright-тести: delayed/error/retry, фільтри, деталі, навігація, 415 px, історія.
5. Збірка й перевірки, незалежне кодрев'ю, виправлення знахідок, браузерне пострев'ю готової версії.
6. Записати фактичні результати/обмеження, перевірити diff, закомітити зміни за завданнями та відправити в GitHub `main`.

## Результати

Реалізовано P01–P10. Карта, лічильники та нова стрічка «Записи карти» використовують одну відфільтровану EE-вибірку. Каталог захищений від запізнілих відповідей, показує загальну кількість і переходи до пов'язаних сутностей. Історія використовує напіввідкритий інтервал та час Києва; під час повільних запитів показується час отриманого кадру, а нові кадри об'єднуються без нескінченного скасування.

Незалежне кодрев'ю додатково виявило й закрило: застарілу картку вибраної сутності, непідтверджене твердження про відсутність тривоги в регіоні, скасування запиту при прямому переході history → live та перекриття стрічки панеллю історії після зміни розміру/періоду. Повторне рев'ю цих виправлень не залишило блокерів у перевіреному обсязі.

Локально: TypeScript і обидві production-збірки пройшли; 27 unit-файлів / 139 тестів пройшли. Lint не має помилок, але має попередження. Збірка попереджає про розмір JS та sourcemap Tailwind.

Пострев'ю через In-app Browser на `http://127.0.0.1:5195` з читанням API `:8090`: підтверджено статус «дані отримано», пошук «Київ» (2429 → 199 записів, однакові числа у фільтрах і стрічці), каталог «100 із 3001», стан оновлення й час після успіху. Ці числа — лише знімок перевірки. Повторну мобільну візуальну перевірку інструментом не вдалося надійно завершити.

Локальний повний Playwright-запуск завершився таймаутом інфраструктури (30 сценаріїв не виконано); це не успішний E2E. У [фінальному GitHub CI](https://github.com/sql-monk/Puluj-g/actions/runs/35933312401) виконано **66/66** desktop/mobile сценаріїв без flaky/skip. Перевірено delayed/error/retry, каталог, виділення, історію, клавіатуру, вузькі екрани та зміну періоду/розміру. CI також виявив втрату прокрутки при швидкому переході до деталей; виправлено й перевірено детермінованою регресією. Докладні докази та інтеграція в `main` через PR №78 — у звіті `gui-remediation-2026-09-24.md`.

Контейнер `:8090` у межах цієї роботи не перевстановлювався; локальний preview і GitHub-доставка не є доказом оновлення розгорнутого контейнера.
